# 20 - Assessment

The pre-beta assessment corpus (`00-inventory.md` → `08-documentation-
audit.md`, `ASSESSMENT.md`, `TRIAGE.md`), assessed 2026-08-21/22.

**This corpus is a frozen historical record, preserved as originally
written.** Its prose describes the repo state *as observed at assessment
time* — including file layouts, `.gitignore` rules, and paths (e.g.
`docs/assessment/`) that were accurate then and have since changed under
the 2026-08-26 D6 documentation restructure. Those mentions were
deliberately **not** rewritten to match today's structure; doing so
would falsify what the assessment actually found. For current repo
structure and standing rules, see `CLAUDE.md`.

`TRIAGE.md` is the exception in spirit if not in location: it's the
ruled disposition record derived from this assessment and remains
**authoritative** — read it before any build or design work, per
`CLAUDE.md`.
