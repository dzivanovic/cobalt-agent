You can easily automate the export of Stock data to a .csv file using code. Follow these 4 steps to obtain the file URL.

  • 1

    Configure Stock Page

    Open stock page of your desired stock and select timeframe

    Open Stock Overview (MSFT)
  • 2

    Replace URL Path

    Change "stock" to "export/stock" in your URL

    Stock URL
    https://elite.finviz.com/stock?t=MSFT&p=d
    Stock Export URL
    https://elite.finviz.com/export/stock?t=MSFT&p=d

    Use the path shown above (/export/stock). Legacy URLs with a .ashx suffix still work but respond with a 301 redirect — tools that don't follow redirects by default (such as curl) will return an empty body. Pass curl -L (or the equivalent flag in your client) to follow the redirect.

  • 3

    Customize Parameters Optional

    API has extra parameters that you can specify in the URL

    Example Export URL with Custom Params
    https://elite.finviz.com/export/stock?t=MSFT&p=d&r=ytd

    This example exports Year to Date data for MSFT, valid ranges: d1, d5, m1, m3, m6, ytd, y1, y2, y5, max

  • 4

    Add Authentication

    Append your API token to the URL

    REDACTED-FINVIZ-API-TOKEN
    Example Export API URL
    https://elite.finviz.com/export/stock?t=MSFT&p=d&auth=REDACTED-FINVIZ-API-TOKEN

Code Examples

Google Sheets Code Snippet
=IMPORTDATA("https://elite.finviz.com/export/stock?[tickerAndTimeframeAndOptionallyDateRange]&auth=REDACTED-FINVIZ-API-TOKEN")
