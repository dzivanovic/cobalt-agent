### Decision (decided-with-veto): soft switch, default ON
`/no_think` in the system message or the last user message turns thinking off for that request;
`/think_low` sets reasoning effort low. Default behaviour unchanged (thinking on — the 27B's
tool-calling was 14/14 with thinking on). Consumers opt out: Cobalt's local-tier adapter per task
class (ADR-0008 contract); the Qwen seat via `/no_think` in QWEN.md (lands in the system prompt).
Alternative (not recommended): hard-off in the template → every caller loses thinking, and the
ADR-0008 adapter gets no per-task control.

installs it into the model dir before every load (original saved once as `.orig`, only if its
sha matches the known upstream `c3cf9e34…`; unknown template = FATAL), so the F1 self-heal reload
and the launchd start serve the same template. The 09-08 "why isn't `/no_think` working" class of
question then has one answer in git.
