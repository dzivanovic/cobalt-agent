# SESSION-CLOSE — the close routine

A session is closed only by this routine. The close hub runs it from `~/cobalt` on `main`; every step leaves its evidence in the file it names. The hub PROPOSES and MEASURES; the desk APPLIES (L58). Memory rules: INDEX `rules:` and [[writing-rules]].

| # | Step | Runner | Where | Evidence |
|---|---|---|---|---|
| 1 | **Ledger appendix**: one dated line per ruling, decision and state change; no narration. | hub | `docs/00 - Project/PROJECT-LEDGER.md`, `### YYYY-MM-DD — …` | the appendix block |
| 2 | **Laws fold**: separate law from record; every candidate listed under `Laws fold — PROPOSED, NOT APPLIED` with his words (from `cto-<date>-words.md`), the time, the exact fold text and its `R<n>`. The desk folds: an amendment rewrites the entry, the replaced wording moves to `LAWS-HISTORY.md`; a new law takes the next free number; the same edit writes or rewrites that law's `## Index` line. | hub proposes · desk applies | `reports/close-<date>.md` → `LAWS.md`, `LAWS-HISTORY.md` | the list; the LAWS diff; `grep -c "^### L"` = `grep -c "^- \[\[LAWS#L"` on `LAWS.md` |
| 2a | **Lessons gate:** audit every practice line and every numbered lesson item since the last completed lessons audit. Each maps to a checklist rule preserving its instruction. Accept existing citations during migration. List every missing mapping under `Checklist — OWED`; advance the audit boundary only after the desk applies all owed rules. File `updated:` is not the audit boundary. | hub proposes · desk applies | `reports/close-<date>.md` → `topics/cto-desk-checklist.md` | the OWED list |
| 4a | **Ladder + backlog status**: under the current sprint's heading, rewrite ONE `### Status <date>` block — per feature / owed prompt `DONE-LIVE · DONE-DARK · BUILT-NOT-MERGED · NOT STARTED` with evidence (tag, commit, report); the stop date; `ON TIME / AT RISK / LATE` with the reason; every sizeable OFF-LADDER item with its ruling. Align `BACKLOG.md`. Status only: scope, dates and order change by his ruling. | hub | `docs/00 - Project/SPRINT-LADDER-v0_1.md`, `BACKLOG.md` | the status block |
| 3 | **`## NOW`** rewritten whole from live evidence (`git log -1`, heartbeat, job rows), never from the previous NOW: main commit, LIVE, RED, the sprint line (`S<n> · stop <date> · ON TIME / AT RISK / LATE`, from the ### Status block this close just wrote), approved designs, pending rulings, ops queue. | desk | `areas/cobalt.md` | `awk '/^## NOW/{f=1} /^## What Cobalt is/{f=0} f' areas/cobalt.md \| wc -m` |
| 4 | **Areas / topics**: the day's rulings and facts, each in its one home ([[writing-rules]] WHERE); a superseded line moves to `_retired/<file>.md`. Bump `updated:` of every file touched and that file's line in INDEX. | desk | `6 - Permanent/Memory/` | the lines written |
| 5 | **Always-loaded block**: `wc -m INDEX.md profile.md preferences.md` in the memory folder, under 4,000. Over = the close FAILS: the hub proposes the exact move to `topics/working-contract.md`; the desk applies it; the hub re-measures. Before and after in the report. | hub measures | memory folder | the two totals |
| 6 | **Commit**: one commit on `main` for the session's docs; machine-written files as-is (L51); `COBALT_ENV=production uv run cobalt validate` exit 0 first. | hub | `~/cobalt` | `git log -1` |
| 7 | **Push** on his word (L55). The report ends `CLOSE COMMITTED <hash> · PUSH: on his word · ESCALATE: <n>`; the next opener goes in the same message. | desk | chat | the report's last line |
