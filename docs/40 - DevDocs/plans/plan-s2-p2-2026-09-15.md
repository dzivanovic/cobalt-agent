## §0 Headline

- New scan-job stage **S5 evaluate** in `com.cobalt.radar` (R1). It parses every `trade_def`'s existing §10.5 `expr` preconditions and avoids into a typed AST (R3) and evaluates them on 2m bars aggregated from `system.bars` i1, with zero tokens. **Rubberband is evaluable end-to-end.** The other five parse and report "not evaluable: missing atoms […]" and never make a fake card (R2, L1). Extension path B is not evaluable until the desk supplies catalyst (R4).
- When Rubberband forms on a pool name, a **WATCH card** lands in `"user".aset_sizings` (origin=radar). It carries setup → trade, trigger, structural stop, proposed key, dots with WHY, and `conviction`/`proximity`/`card_score` with scan id + formula/tunables/settings hashes (L57).
- **Dots:** every dot the engine computes runs in **shadow** in P2 (R6): the four computable Rubberband dots and the three desk dots. They are stored with WHY, shown in reasons, hollow on the face and tappable. Conviction = mean of Dejan's taps, so `card_score` is null until he taps (settled rules: no neutral 5, empty set → null).
- **Ladder + tap:** keys A+/A/B/C/pass with dollars read live from `trader_settings`. A tap records the tapped grade and sizes at the nearest enabled key **below**, with a loud notice; nothing enabled below → refused (R8). ProposedKey bands live in `trader_settings` (R7). Promote ↑ and the tap strip go live on `/radar`. The 8 `card.health.*` rows come with the health computer.
- **Seam as DDL:** `system.radar_score_run`, `system.radar_score`, view `system.radar_board_v`; desk tables `system.desk_regime`/`desk_packet`/`desk_grade` created empty. A daily-bars collector serves `htf_level_proximity` and the HTF avoid, counted in the Finviz total-demand ceiling (R5).
- **Ships dark.** `radar.cards_enabled=false` writes seam rows only. Cards reach production only when Dejan runs `cobalt settings load --apply` himself, after the dev replay proof and the OpenAI-house recompute (R9, R11). Taxonomy v0.8 (`catalyst` standard) migrates the 13 notes through one review file + one batch apply (R10).
- ESCALATE: 5 (§8). EV never renders in P2: n<30 everywhere (L8). Dots display 1–10 with WHY regardless of n (09-14 group-2 ruling).

## Context — why

S2-P1 is live: a pool of 50, bars every 100 s. S2-P3 (read-only `/radar`, merging first) shows an empty ladder in production and FAILS on any radar card because its adapter is unwired. The 09-14 tribunals settled the ranking authority (`card_score`), the seam, the dot set (`catalyst` + desk-graded alignment, shadow through S2) and the missing-data rules. P2 turns them into cards.

- **STEP-2 grammar (`src/cobalt/taxonomy/predicate.py`, R3):** a tokenizer + recursive-descent parser over §10.5 atoms (`Object(arg).field`, `==`/`IN {…}`/`>=`/`<=`/`>`/`<`, `AND`/`OR`/`NOT`, `cfg(key)`, `event(name)`, arithmetic `*` on numbers) → frozen Pydantic AST. It is parsed at `TradeDef` validation. A syntax error fails loud with slug + expression; an unknown `cfg` key fails loud (F16 charter). `required_atoms(ast)` names the detectors a def needs. `text` predicates stay human.
- **STEP-3 detectors (`src/cobalt/radar/anatomy/`, pure functions over bars, R2/R4/R5):** 2m bars via `archiver.aggregate`; `ATR(working_tf,14)`; daily `ATR(14)`; volume MA+2σ; Leg (terminated by ≥1 opposing bar); `Extension{instantiated, state ∈ culminating|none, path, leg_count, direction}` — path A only; path B → `not_evaluable: catalyst_ref unknown`; `snapback_candle` (tracked extreme of the run); `bar_break` trigger price from the last `cfg(rubberband.bars_cleared)` completed bars; structural stop = extreme ± `cfg(stop.buffer)` + stop-nudge check-and-move (§0 A.17); daily-level refs (prior-session H/L/C) for `htf_level_proximity` and `RangeBreak(HTF).day_count`. - **STEP-4 S5 evaluate stage (`radar/runner.py` + `radar/evaluate.py`, R1/R9):**
  - Runs after S4 behind the same commit gate. It opens a `radar_score_run`, loads defined trade_defs through `TradeDefStore` (user side, SELECT on system bars), and evaluates each open member × def.
  - An input older than 2 × `radar.scan_interval` → `input_stale`, the grade is suppressed, and the prior value is kept only in `card_dots.history` (09-14 group-2 B).
  - Failure → `failed_stage='evaluate'` with detail; S1–S4 results stand.
  - Formation + `radar.cards_enabled=true` + no open radar card for (member, def, direction) → create the card row + genesis WATCH transition (actor cobalt, evidence = run id, formation bar ts, atoms) + `card_dots` in one transaction, through `AsetStore`/`CardStore` (one path).
  - Each scan updates proximity/last and copies the card's conviction/proximity/card_score into the run's `radar_score` row.
  - Expiry via `cards/expire.py`: end of the last `preferred_windows` sub-window, an avoid turning true, or the stop touched before arm → EXPIRED with evidence.
  - `cards_enabled=false` → seam rows only.
  - Dry-run CLI `cobalt radar evaluate --replay <date> [--trade-def slug]` reads `system.bars` and writes nothing.
- **STEP-5 dots + scoring (`src/cobalt/cards/scoring.py`, R6/R7):**
  - One dot per `quality_factors[]` entry. `source: cobalt` factors → computed value → grade via `card.curves` piecewise-linear anchors (clip 1–10, round half-up once) + WHY template, **role=shadow**. Missing anchors → `na_reason: curve_unset`.
  - `trail_fit` → N/A (MANUAL). A human factor is hollow.
  - Desk dots: `catalyst` → `DESK_NA`. `market_alignment` / `sector_alignment` → default with/flat/against map from context bars (09-14 group-2 A; values from `trader_settings` `card.alignment_default`, `flat_pct` 0.15 accepted default); missing context → `CHECKPOINT_MISSING`. Stored in `radar_score.desk_shadow` and mirrored onto the card's hollow dot reasons as `desk shadow: n`.
  - `conviction = mean(trader_grade of tapped dots)/10`; no taps → null. A required computed dot that is N/A and untapped (trail_fit) → `score_suppressed` with the reason (settled rule). `proximity = clamp(1 − |last − trigger| ÷ (3 × |trigger − stop|), 0, 1)`; `card_score = round(conviction × proximity × 100)`.
