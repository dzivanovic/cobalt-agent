# F4 / F5 seam · 2026-10-10

Settles the shared files of F4 (prefill all day, Charter:82-87) and F5 (market-context checkpoints, Charter:89-93) per LAWS:363. The F4 card and the F5 card cite this file before either launches.
Code base: `d0a5fbb8`. F4 design: `f4-design-proposal-2026-10-10.md`.

## 1. Order
- F4 builds, checks and merges first (his R849, `cto-2026-10-10.md:22`).
- F5's design and tribunal run in parallel with F4's; F5's build branches from `main` AFTER F4's merge and rebases on nothing else of F4's.
- F5 edits no F4-owned line. A need F5 finds in an F4-owned line is a row on F4's card (same card, L-text LAWS:375), never an F5 edit.

## 2. `src/cobalt/prefill/daily.py`
- Owner: F4. F4 adds `run_daily_refresh()`, the ownership logic, the stamp/flag line, and three public helpers F5 imports:
  - `daily_note_path(when) -> Path` — today's note path (from `daily.py:484-485`).
  - `ensure_daily_note(writer, when) -> WriteResult` — `create_if_absent` with the daily template context (the `daily.py:548` path).
  - `format_stamp(when) -> str` — `as of HH:MM ET` via `SessionClock.to_et`.
- F5: imports those three; adds nothing to `daily.py`. F5's code lives in its own module (default `src/cobalt/prefill/checkpoints.py`) with its own `VaultWriter` name (default `prefill.checkpoint`).
- F4's `SLOT_SPECS` (`daily.py:463-473`) and refresh set never list F5's section; F5 never lists F4's.

## 3. `configs/cobalt/prefill.yaml`
- The `prefill:` mapping (`prefill.yaml:7-17`, `PrefillPathsConfig` `extra="forbid"`, `prefill/config.py:107-118`): neither feature edits it.
- F4 adds top-level `daily_refresh:` (its own model). F5 adds top-level `checkpoints:` after it (its own model, its own loader via `_load_yaml_mapping(..., "checkpoints")`, `config.py:121-127`).
- Each block is loaded only by its owner; a key in the other's block is never read.
- Both edits restart `com.cobalt.aset` (it reads `prefill.yaml`, `jobs.yaml:81`); each deploy card names that restart (L42).

## 4. `configs/cobalt/jobs.yaml`
- F4 adds row `com.cobalt.prefill-refresh` directly after `com.cobalt.prefill-daily` (`jobs.yaml:207-212`), and appends that label to the `daily.md.j2` readers (`jobs.yaml:330-335`).
- F5 adds its checkpoint row(s) directly after F4's row. F5 appends its label(s) to the `daily.md.j2` readers only if its job calls `ensure_daily_note`.
- Neither edits the other's row or any other row.
