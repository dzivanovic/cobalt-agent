# `src/cobalt/radar/handicap_dry_run.py`

The float handicap's dry-run (FLOAT-HANDICAP-v3 §7 (1), [F-16], X12) and the one cache reader it shares with the H1 first-gate experiments. It reads the retained screener exports under `radar.yaml`'s `cache.dir`, groups each UTC day folder's files into scans by the collector's own file naming (one `HHMMSS` = one cycle; the nightly replay's mover exports are recognised by `replay/movers.py`'s regex and set apart; any other file fails the grouping loudly), and rebuilds every scan's sources by calling the resident radar's own `RadarRunner._collect` over a collector that serves the cached files, so cell parsing and the not-equity rule are production's. A scan whose cache lacks a source the note names degrades that source, exactly as a failed fetch did. `replay_day` then runs `decide()` scan by scan, carrying open episodes forward from its own transitions the way the store would record them; the first scan of a day starts empty.

`identity_mismatches` is X12: the note's pool block with the handicap absent against the same block with a handicap at factor 1, comparing every pre-H1 transition field (`CORE_FIELDS`) and the order, plus `raw_rank == rank`. `dry_run` produces [F-16]'s per-scan lines — members in and out, the handicapped names that would keep or lose a seat and who would take it (would-be seats before stickiness), the tier of every cut, the scans where a dead column made the handicap inoperative — with the header names read and five raw cells, and `n` as days and scans. The "keeps its seat iff p ≤ h × c" sentence is never printed: experiment X2 found cuts decided by stickiness and priority. `stored_mismatches` compares the `h = 1` pass with stored membership, matching a stored scan to a cached one by its second. `command` is `cobalt radar handicap-dry-run --day <d>`: it refuses a malformed day or a day not in the cache loudly, reads the note through the normal reader, prints the report, the identity count when his note carries a block, and the stored-membership comparison. It writes nothing.
