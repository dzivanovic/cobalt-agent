# `ops/fetch_voice_models.py` (+ `ops/fetch-voice-models.sh`)

## 2026-10-08 — stt-model-fix-1008

New: the one model-fetch command (design `VOICE-TTS-DRAFT-FINAL-2026-09-25.md` [F-30], `:317`), run by hand through `sh ops/fetch-voice-models.sh [--from <dir>]`. It fills `model_dir` with the pinned `stt_model` / `stt_revision` snapshot of `configs/cobalt/voice.yaml`, so `transcribe.model_present` is true and the widget's `speech-to-text down (model missing)` banner clears per request, with no restart. It reads no mode and never calls `load_voice_config()`: the four values come from the YAML, `COBALT_VOICE_MODEL_DIR` overrides `model_dir` as the loader does, and `_check_path`'s refusals run, all but the resolved vault's. A present model is left alone. `--from <dir>` copies the snapshot's `models--Systran--faster-whisper-<model>` folder whole with its relative links, and never touches the network; a source without the snapshot, or a target already holding that folder, is `FAILED`, exit 1, with nothing written or deleted. With no `--from`, it runs the one download in Cobalt. The last step checks `model_present` and does an offline `_load_model`, then prints `voice model READY: <model> <revision> at <snapshot>`. Tests: `tests/ops/test_fetch_voice_models.py`. `restarts.OPS_TOOLS` lists both paths.
